# Installation of uv

This tool manages Python versions, environments and dependencies ([Official documentation](https://docs.astral.sh/uv/getting-started/installation/?utm_source=chatgpt.com)).

Version used : 0.13.6

## Installation command

### Windows 11

``` bash
winget install --id astral-sh.uv -e
```

Specific version (replacing [version] by its identification, here 13.0.6):

``` bash
winget install --id astral-sh.uv -e --version [version]
```

### Linux

Generic :

``` bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Specific version (replacing [version] by its identification, here 13.0.6):

``` bash
curl -LsSf https://astral.sh/uv/[version]/install.sh | sh
```

## Verification

``` bash
uv --version
```

## Enforce minimal version

In the `pyproject.toml`, adding the following line enforces the version of `uv` :

``` toml
[tool.uv]
required-version = ">=0.13.6"
```

Setting "==" instead of ">=" enforces strict version instead of minimal version.
