# Installation and setup of Python

This notice explains the installation and set up of a clean Python environment using uv (See [0.1 - Installation - Dev Env - uv](<./0.1 - Installation - Dev Env - uv.md>)).

## 1. Prerequisite

* uv 0.13.6

## 2. Python installation

Python is fully managed by `uv`. 

As a personal choice to avoid file names, installation directory has been configured at system level with `UV_PYTHON_INSTALL_DIR` environment variable to place interpreters in `Program Files`, closer to the root and user independent, but placing it in a user profile (default) also works.

Version : **CPython 3.14.10**.

Installation :

```bash
uv python install 3.14.10
```

Verification :

```bash
uv python list 3.14
```

## A - Initial build

### A-1. Initialisation of the project

From project root folder :

```bash
uv init --bare --python 3.14.10
```

The `.python-version` isn't created automatically by that command, so we can manually add it in the same folder with the following content :

```text
3.14.10
```

Virtual environment creation:

```bash
uv venv --python 3.14.10
```

Verification :

```bash
uv run python --version
```

Expected result : `Python 3.14.10`.

The environment is kept in `.venv/`, at the project root.

**Command execution :** Python commands will be executed using `uv run` without explicit activation of the environment, to avoid changing shell policies.

### A-2. Dependencies

#### Main dependencies

```bash
uv add psutil pandas matplotlib pyyaml
```

| Library      | Version | Usage                                     |
| ------------ | ------: | ----------------------------------------- |
| psutil       |   7.2.2 | Watch process and system resources        |
| pandas       |   3.1.0 | Data manipulation                         |
| matplotlib   |  3.11.2 | Data visualization                        |
| PyYAML       |   6.0.3 | Management of YAML configurations         |

#### Dev tools

```bash
uv add --dev pytest ruff
```

| Tool   | Version | Usage                     |
| ------ | ------: | ------------------------- |
| pytest |   9.2.0 | Automated tests           |
| Ruff   |  0.17.3 | Code analysis and linting |

`uv.lock` keeps track of dependencies, including their versions.

### A-3. Installation verification

Main dependencies import :

```bash
uv run python -c "import psutil, pandas, matplotlib, yaml; print('Dependencies OK')"
```

Expected result : `Dependencies OK`.

Tools verification :

```bash
uv run pytest --version
uv run ruff --version
```

Environment syncronization :

```bash
uv sync
```

Expected result : Synced environment, without additional dependencies.

Display dependencies :

```bash
uv tree
```

## B - Rebuild environment

For a new installation, instead of going through all the previous steps, recovering the files from github simply requires  going through the initial `uv` and raw `Python` installation and then executing the following command at the project root :

```bash
uv sync
```

This command line rebuilds the environment from the `uv.lock` file and project configuration.

Tracked files on github :

* `pyproject.toml` : configuration and project dependencies ;
* `uv.lock` : resolved versions ;
* `.python-version` : expected python version.

`.venv/` is a local repository : it is NOT tracked by git.

---

**Final state :** Operational Python environment with checked dependencies and locked versions.
